# Ícones do PokeIdle Hub

Coloque aqui os arquivos de ícones (preferencialmente em formato **.svg**, ou **.png** transparente de 24x24 / 48x48 px).

## Nomes e Finalidades dos Arquivos

### 1. Navegação Principal (Sidebar / Módulos)
- `nav-lives.svg` — Ícone da aba Lives (transmissão / antena / broadcast).
- `nav-game.svg` — Ícone da aba Jogo (controle de videogame / gamepad).
- `nav-alerts.svg` — Ícone da aba Alertas (sino de notificação / bell).
- `nav-afk.svg` — Ícone da aba Farm AFK (calculadora ou gráfico de desempenho).
- `nav-focus.svg` — Ícone de Tela Limpa / Modo Foco (expandir tela cheia / maximize).
- `nav-clean-ram.svg` — Ícone de Otimizar Memória RAM (chip de CPU ou vassoura).

### 2. Ações de Lives
- `action-add.svg` — Adicionar canal (sinal de adição / plus).
- `action-columns.svg` — Colunas e grade (layout de grade / grid).
- `action-chat.svg` — Chats (balão de conversa / message-square).
- `action-video-hide.svg` — Ocultar vídeos (olho riscado / eye-off).
- `action-video-show.svg` — Mostrar vídeos (olho aberto / eye).
- `action-mute.svg` — Silenciar áudio (alto-falante mudo / volume-x).
- `action-unmute.svg` — Ativar áudio (alto-falante com som / volume-2).
- `action-follow.svg` — Seguir canal (usuário com sinal de mais / user-plus ou coração / bookmark).
- `action-reload.svg` — Recarregar lives (seta circular / refresh / rotate-cw).
- `action-star.svg` — Favorito ativo (estrela preenchida).
- `action-star-outline.svg` — Favorito inativo (estrela de contorno).
- `action-trash.svg` — Limpar ou remover (lixeira / trash).

### 3. Ações do Jogo (Game Bar)
- `game-mosaic.svg` — Modo Mosaico (ver todas as contas em grade / layout grid).
- `game-single.svg` — Conta Única (janela única focada / maximize).
- `game-key.svg` — Login Google / Autenticação (chave / key).
- `game-link.svg` — Conectar contas Twitch/Kick (elo de corrente / link).
- `game-edge.svg` — Abrir no navegador Edge (globo / globe).

## Dica de Formato
Se os SVGs utilizarem `stroke="currentColor"` e `fill="none"`, eles mudarão de cor automaticamente conforme o tema e os estados de hover do app.
